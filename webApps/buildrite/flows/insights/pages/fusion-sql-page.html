How it works

Fusion gives no database connection. Build.Rite sends your SELECT, base64-encoded, to one BI Publisher report on the pod (the query runner): its data model runs it with DBMS_XMLGEN, which returns any query as XML rows, through BI Publisher's runReport web service. Only SELECT and WITH run, each statement capped by the row limit, as the Fusion user you sign in with — that user needs BI Consumer and the data roles for what you read (BI Author once, to deploy).
