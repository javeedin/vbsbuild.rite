How it works

BIP Reporting calls BI Publisher's own web services on the pod (CatalogService and ReportService, SOAP), as the Fusion user of the pod chosen above — the pods, their logins and the API calls are Fusion SQL's (Fusion SQL → Connection, and its API Inspector). A report runs with its own layout or as data (CSV / XML, shown as rows). With buckets a big report runs once per day / week / month… of a date range and the rows are joined into one table. A big output comes in chunks. Every run — what was asked, the output file, its rows — is kept on this PC; the catalog and the reports' parameters are kept too, until Refresh.
